## 📖 What is this? (Yeh kya hai?)

Ek simple **web app** jo DVSA ke driving test slots check karta hai.  
Jaise aap manual check karte ho waise hi, but ye **automatically** check karta hai!

**Kaam kaise karta hai?**
1. 👆 Aap website open karte ho
2. 🤖 App automatically 9 London test centres check karta hai
3. 🔔 Jahan slot milta hai, wahan notification aata hai
4. ✅ Aap direct DVSA site par booking kar sakte ho

---

## ✨ Features (Kya kya hai isme?)

| Feature | Explanation |
|---------|-------------|
| 🔍 **Auto Monitoring** | Har 15 minute mein apne aap check karta hai |
| 🔔 **Desktop Notifications** | Slot milte hi alert aata hai |
| 🔊 **Sound Alerts** | Awaaz bhi aati hai taaki pata chal jaye |
| 📊 **Live Stats** | Kitne centres mein slots hain, sab dikhta hai |
| 🌓 **Dark Mode** | Raat mein aankhon ka dhyan rakhta hai |
| 📱 **Mobile Friendly** | Phone par bhi theek chalta hai |
| 💾 **Local Storage** | Aapki settings save ho jaati hain |
| 🎉 **Celebration Effect** | Slot milne par confetti udta hai |
