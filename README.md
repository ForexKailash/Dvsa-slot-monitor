# 🚗 DVSA Driving Test Slot Monitor

Monitor driving test slots in real-time for London test centres.

## Features
- Real-time slot monitoring for 9 London test centres
- Desktop notifications when slots become available
- Sound alerts and visual celebrations
- Alert history tracking
- Configurable check intervals
- PWA support for mobile
